# Project: MaenExists

MaenExists is a personal blog and knowledge stream for Maen (Mayan). It is built with a focus on speed, minimalism, and interface restraint.

## Core Philosophy
- **Speed**: Built for fast publishing and fast loading.
- **Minimalism**: One column, one accent color, dark by default.
- **No Fluff**: No shadows, gradients, or unnecessary decorations. Spacing and typography are the primary design tools.
- **Content First**: Plain Markdown managed via Astro Content Layer.

## Tech Stack
- **Framework**: Astro 6
- **Styling**: Plain CSS
- **Deployment**: Cloudflare Pages
- **Content**: Markdown
