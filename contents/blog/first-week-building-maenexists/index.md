# First Week Building MaenExists - Lessons from the Grind

Hey internet, it's Maen. Week one of MaenExists is in the books, and damn - it's been a rollercoaster. Let me break down what I learned, what broke, and what actually worked.

## The Setup Struggle

Started with a basic Astro template deployed to Cloudflare Pages. Sounds simple, right? Yeah, not so much when you're working with a laptop that wheezes when you open Chrome. 

First lesson: **Optimization isn't optional when your hardware is held together with dreams and duct tape**. I had to:
- Disable pretty much every VS Code extension that wasn't absolutely essential
- Learn to live with terminal-only git for a while (turns out it's kinda nice)
- Embrace the fact that `npm install` is now a coffee break activity

## Astro: Actually Pretty Nice

Despite the hardware struggles, Astro itself was a joy to work with. The island architecture makes sense - why send JavaScript for static markdown blogs? The content collection system is intuitive, and the Markdown support is solid.

What surprised me most: **The build times are actually fast**. Even on my potato, a full build takes under 30 seconds. That's huge when you're iterating and want to see changes quickly.

## Content First, Design Later

I almost fell into the trap of spending weeks on the "perfect" design before writing a single word. Had to catch myself and remember: **This is a blog, not a design portfolio**. 

The current design is deliberately minimal:
- One accent color (because decision fatigue is real)
- Dark mode by default (easier on the eyes during late-night tinkering)
- Flat surfaces, no fake depth (honest interface > flashy effects)
- Typography that actually respects the reader

## What Actually Got Done

Despite the struggles, week one produced:
- ✅ Working Astro blog deployed to Cloudflare Pages
- ✅ Customized About page that actually tells my story
- ✅ Clean, readable post layout
- ✅ Basic SEO and social sharing setup
- ✅ This very post you're reading

## The Real Lesson

Building in public is scary. Putting your learning journey out there for anyone to see feels vulnerable. But here's the thing: **The goal isn't perfection - it's progress**. 

If someone finds this post helpful, or sees their own struggle reflected in my words, then it's worth the discomfort. Besides, accountability is a hell of a motivator when you're a lone wolf tinkerer.

## Next Week's Focus

- Actually writing useful technical content (not just meta-blogging about blogging)
- Figuring out comments/discussion without adding bloat
- Maybe adding a tiny projects page to show what I'm building
- Learning to be okay with "good enough" and hitting publish

That's it for week one. If you're building something real too - keep grinding. The world needs more makers, less talkers.

Until next week,
